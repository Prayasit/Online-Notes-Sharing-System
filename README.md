# 📚 Online Notes Sharing System

A Django-based web application for uploading, managing, searching, and sharing academic notes.

## 📌 Overview

The **Online Notes Sharing System (ONSS)** is a web-based platform designed to provide a centralized place for students and teachers to upload, manage, search, and access academic study materials.

The system provides user authentication, note management, search functionality, and a dashboard-based interface for accessing academic resources.

## ✨ Features

- 🔐 User registration and login
- 👤 User profile management
- 📤 Upload academic notes
- 📝 Update and manage uploaded notes
- 🔎 Search notes
- 📚 Browse available notes
- 📥 Download shared study materials
- 🔑 Change password
- 📊 Dashboard for managing notes and user activities
- 🖥️ Responsive web interface
